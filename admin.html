✅ ¿Cómo aplicar estas reglas?

  1. Ve a la consola de Firebase (console.firebase.google.com).
  2. Entra a tu proyecto turepuestoya.
  3. En el menú izquierdo, haz clic en Realtime Database.
  4. Arriba, selecciona la pestaña Reglas (Rules).
  5. Borra todo lo que haya allí, pega el código copiado y haz clic en Publicar.

⚠️ ¿Cómo REVERTIR las reglas si ocurre algún error?

Si notas que la app deja de funcionar, puedes restaurar el acceso público temporalmente pegando este código básico:

{ "rules": { ".read": "true", ".write": "true" } }
